# ORVNT Narrative

Build a premium cinematic website for ORVNT, a technology and venture company.

IMPORTANT:
Use the uploaded ORVNT HTML file as the visual/structural starting point.
Preserve and reuse the existing ORVNT logo/ring mark and the existing brand color system.

DO NOT create a generic SaaS landing page.
DO NOT use generic startup gradients, excessive rounded cards, stock illustrations, or cliché AI imagery.

The website should feel like a premium technology company / future systems studio / venture company.

BRAND:
ORVNT
BUILD · INTELLIGENCE · IMPACT

Brand colors:
#0A0A0D — black
#121214 — dark surface
#1F2024 — secondary surface
#F5F5F7 — off-white
#CDAA7D — ORVNT gold

Design language:
- black/off-white cinematic contrast
- subtle champagne-gold highlights
- thin borders
- large editorial typography
- generous negative space
- premium minimalism
- sophisticated motion
- futuristic but not gimmicky
- Apple / Linear / high-end technology studio level polish
- 3D depth throughout
- smooth scroll-driven transitions
- subtle parallax
- mouse-reactive lighting
- glass only when visually justified
- no excessive gradients

CORE EXPERIENCE:

The website should feel like one continuous visual story rather than a collection of disconnected sections.

SECTION 1 — ARRIVAL / LOGO

When the user first enters the site:

- full-screen black background
- center the ORVNT ring logo
- logo appears slowly with a subtle gold glow
- very subtle rotation/breathing effect
- minimal "BUILD · INTELLIGENCE · IMPACT" beneath it
- initially hide the main navigation
- create a premium cinematic entrance
- after the first scroll, transition naturally into the main website

Show ORVNT in extremely large typography occupying most of the viewport.

SCROLL EXPERIENCE:

This is critical.

Use:
- smooth scroll
- scroll-triggered text reveals
- parallax
- scale transitions
- horizontal movement
- 3D transforms
- section-to-section morphing
- subtle particle effects
- mouse-following light
- perspective hover
- magnetic buttons
- animated progress rail on desktop

The current HTML already contains a scroll rail. Preserve the concept and improve it.

PERFORMANCE:

Use performant CSS transforms and requestAnimationFrame where necessary.
Respect prefers-reduced-motion.
Do not allow animations to block interaction.
Lazy-load heavy visual effects.
Keep mobile performance strong.

RESPONSIVE:

Desktop:
Maximum cinematic experience with 3D effects.

Tablet:
Reduce particle density and simplify 3D.

Mobile:
Keep the storytelling and typography but reduce heavy WebGL/particle effects.
Navigation becomes a clean mobile menu.

IMPORTANT DESIGN RULE:

Every section must feel connected to ORVNT's identity.

The user should leave the website thinking:

"ORVNT builds intelligent systems and ventures for the future."

Not:

"This is another software agency website."

Prioritize visual storytelling, typography, motion and spatial depth over having lots of text.

The logo and color palette from the uploaded HTML are authoritative. Do not replace the ORVNT logo with a newly generated logo.
